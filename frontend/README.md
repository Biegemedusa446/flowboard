# Flowboard  Trello-style Frontend

A dark, Trello-like three column UI with
1. Weather for a week with high low current humidity and precipitation
2. Todos and calendar entries
3. GitHub activity
Plus a top suggest bar with buttons like I am bored and Surprise me that recommends quick actions.


Run
1. npm install
2. npm run dev
Open http  localhost 5173

API
Set VITE_API_BASE in .env to your backend base URL. If an API is missing, the app uses sample data.
